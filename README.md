# APPs

Apps built on free public data.

| App | What it is | Where |
|---|---|---|
| **Salty** | Tells you in ten seconds whether you are underpaid, using official government pay figures | [`salty/`](salty/) |

How work is done here: changes go on a branch, then a pull request; automated checks (lint, types, tests, build) run on every pull request; features and bugs are tracked as issues. Conventions for anyone, human or AI, working in this repo are in [`CLAUDE.md`](CLAUDE.md).
